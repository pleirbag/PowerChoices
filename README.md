# PowerChoices

Repo for the Powerchoices mod for WW



Current features include: 

Ability to choose what powers can spawn on the match

Host side only - no need for everyone to have it installed

Currently limited to having at least one regular and one special power to avoid crashes

Scrambled mode - Powers and special powers can spawn on any spot




Planned features (no promisses):

Possible support for modded elements



Known Bugs:

Bad interaction with special powers leads to some situations where void is the only spawanable special power, this should not happen frequently
