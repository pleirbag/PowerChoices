# PowerChoices

Repo for the Powerchoices mod for WW

Current features include: 
Ability to choose what powers can spawn on the match
Host side only - no need for everyone to ahve it installed
Currently limited to having at least one regular and one special power to avoid crashes - Preserves as much as possible regular game  power generation

Planned features (no promisses):
Scrambled mode - Powers and special pwoers can spawn on any spot
Possible support for modded elements

Known Bugs:
Having no regular powers selected makes the spots invisible for the host, but still acessible for everyone

Bad interaction with special powers leads to some situations where void is the only spawanable special power
